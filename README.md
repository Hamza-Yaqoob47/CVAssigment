# Corner Detection — OpenCV Experiments

## Project setup

The project compares Shi–Tomasi, determinant/trace (Noble/Förstner-type), and Harris corner responses using OpenCV. The experiments vary derivative support (`ksize`), integration support (`blockSize`), relative response threshold (`alpha`), Harris sensitivity (`k`), and additive Gaussian noise.

### Dependencies

```text
numpy==2.4.2
opencv-python-headless==4.13.0.92
```

Install:

```bash
python -m pip install -r requirements.txt
```

`experiment.py` and `config.json` are **not included** in this package because their source listings were not supplied. Add your own versions in the root folder, and ensure image paths in `config.json` point to the files you plan to use.

**Get the two exact OpenCV source photographs** (internet connection required):

```bash
python download_reference_images.py
```

The folder already includes runnable alternative images (`checkerboard.png`, `coffee.png`), plus the synthetic pair. The two OpenCV photos (`building.jpg`, `fruits.jpg`) are retrieved by the download command above, not bundled in this ZIP.

### Run experiment

```bash
python experiment.py --config config.json --output results
```

The `images/` folder should be next to `experiment.py` and `config.json`. The experiment should save response maps, threshold masks, final corner coordinates (zero-based `(x, y)`), overlays, and a run summary including `alpha`, numerical threshold `T`, and corner count.

## Image sources and reproducibility

| File | Purpose | Source |
| --- | --- | --- |
| `synthetic.png` | Known corners, straight edges, and flat regions | Generated programmatically for this package (512×512 grayscale) |
| `synthetic_noisy_sigma0.02_seed42.png` | Noise comparison | Derived from `synthetic.png` with RNG seed **42**, zero-mean Gaussian noise **σ = 0.02** applied to normalized `[0,1]` intensity values, clipped to `[0,1]`, then saved as 8-bit PNG |
| `building.jpg` | Structured natural scene | OpenCV 4.13.0 `samples/data/building.jpg`, source [2] |
| `fruits.jpg` | Textured/cluttered natural scene | OpenCV 4.13.0 `samples/data/fruits.jpg`, source [3] |
| `checkerboard.png` | Included structured-image alternative | `skimage.data.checkerboard()`, scikit-image sample data [4] |
| `coffee.png` | Included cluttered-image alternative | `skimage.data.coffee()`, scikit-image sample data [4] |

The synthetic and noisy images are bundled; for an exact reproduction of the synthetic-noise experiment from floating-point data, regenerate the noise using `np.random.default_rng(42)`, `normal(0, 0.02, ...)`, and clipping before image quantization. If using the saved PNG, note the 8-bit quantization.
